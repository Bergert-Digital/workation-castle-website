# Pediment block catalog

> Generated by `npm run blocks:catalog`. Edit only the **Use when** notes —
> everything else is overwritten on regeneration. Do not hand-edit other fields.
>
> Pages are composed from core blocks and named block styles. Only the blocks
> in this first part are for new content. The blocks under "Legacy blocks" are
> kept so old content renders; never insert them.

## pediment/blog-index

**Blog Index** — Recent posts as Insight cards with featured image, category badge, and an optional presentational category filter.

**Source:** parent
**Wrapper class:** `starter-blog-index`
**Use when:** a "latest posts" or "insights" section that lists article cards with image, category, and title.

**Attributes:**
  - `count` (number)
  - `categorySlug` (string)
  - `showFilter` (boolean)

**Align:** wide

## pediment/form

**Form** — A form that collects visitor input and delivers it to a configured destination. Add Form Field child blocks for each input. Use for contact, booking, registration, feedback, or signup forms.

**Source:** parent
**Use when:** any visitor form (contact, booking, feedback). Not legacy. Pages written through Pediment's MCP tools reject raw `<form>` markup, so use this block for forms.

**Attributes:**
  - `destination` (string)
  - `successMessage` (string)
  - `submitLabel` (string)

**Align:** wide

## pediment/icon

**Icon** — One icon from the Pediment icon set; decorative, or announced to screen readers when it has a label.

**Source:** parent
**Use when:** an icon on a card or a list item. Set the Phosphor slug in `icon` and add a `label` when the icon carries meaning, so screen readers announce it. Leave `label` empty for a decorative icon. The default style is `tile`.

**Attributes:**
  - `icon` (string)
  - `label` (string)
